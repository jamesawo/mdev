# mdev

## Overview
mdev is a small CLI that automates development environment setup on macOS. It installs and configures common tools so you can get a new machine ready quickly. The project is written in Go.

## Why mdev
I needed a simple way to automate my personal dev setup on macOS, so I built mdev to do exactly that. It captures the tools and steps I repeat across machines and keeps them in one place.

## Usage
Build or run locally:

```bash
make build
./mdev doctor
```
